# FYS5429 – Advanced Machine Learning and Data Analysis for the Physical Sciences

**University of Oslo (UiO)**  
**Repository owner:** Zejing Wang

## Overview

This repository is intended for coursework, exercises, and computational projects related to **FYS5429: Advanced Machine Learning and Data Analysis for the Physical Sciences**.

The goal is to explore how machine learning and data analysis can be used to study scientific data and problems arising in the physical sciences, with attention to both mathematical understanding and practical implementation.

## Areas of Interest

The materials added to this repository may explore:

- Machine learning and data-driven methods for scientific problems.
- Analysis and visualization of data from physical systems.
- Neural networks and their application to numerical or scientific tasks.
- Model evaluation, generalization, and reproducibility.
- Connections between numerical modelling and machine learning.

These are intended areas of focus, not a list of completed assignments.
